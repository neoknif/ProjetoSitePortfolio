# 🌐 Web Project - Estrutura Estática & Deploy na Azion

Este repositório contém a estrutura base e os arquivos front-end de um site estático moderno, organizado com boas práticas de desenvolvimento web e configurado para entrega de alta performance via Edge Computing.

---

## 🏗️ Arquitetura e Organização do Projeto

O projeto foi estruturado seguindo o padrão de separação de responsabilidades (HTML5, CSS3 e JavaScript), mantendo o ponto de entrada principal na raiz e os recursos em pastas dedicadas para melhor organização e manutenção:

```text
/
├── index.html          # Ponto de entrada (Estruturação semântica)
├── css/
│   └── style.css       # Estilização e regras visuais
├── js/
│   └── script.js       # Lógica e interatividade do site
└── README.md           # Documentação do projeto
